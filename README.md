# Peliryhm-ty-
Meijä project :)

Noi kuvat on tehty tekoälyllä, mutta jos se haittaa, voin väsää ne paintissä :)

Explanation, miten viholliset toimii;
  Niillä on vaikeustaso 1-20.
   Ne etenee vaikka 3-5 sekunnin välein.
     Kuitenkin niillä on chänce liikkua 1-20, jonka ne randomisti rullaa.
       Jos esim. vaikeustaso on 10, niin se arpoo luvun 10-20 välillä.
         Jos luku on suurempi kuin 10, se ei liiku, jos pienempi se liikkuu.
           Tällöin 20 tason pahis liikkuu aina 3-5 sekunnin välein.
